# dsh-tokenrhythm-bill

**基元律动费用中心** —— DeepSeek Harness（DSH）插件，把[基元律动 tokenrhythm.studio](https://tokenrhythm.studio) 的模型清单、账户余额、用量与本机凭据池，集中到一个可拖拽浮层面板里。

DSH 侧栏里（「记忆系统 / 技能中心」条目**下方**）有「**基元费用**」条目：左侧品牌标 + 名称，右侧常驻**总余额胶囊**（切凭据即刷、预警转琥珀色）；点它打开可拖拽面板；**悬停条目**可浮出**限时余额时间线**——逐笔列出每笔限时额度和「N 天后失效」（实时计算，无限时额度时不显示）；侧栏收起时只保留品牌图标。

## 功能一览

### 模型
- 顶部**分类筛选**：全部 / 文本 / 图像 / 音频 / 视频 / 向量（带计数，口径与平台模型列表页一致）
- **文本在前、图像在后，价格升序**：图像模型按图片单价、文本模型按输入单价（有折扣取折扣价）；无价格的排组尾，同价内保持平台原序
- 卡片结构对齐平台模型页：**名称 + 状态胶囊**（在线 / 测试中）headline，**模型 ID + 来源**（无问芯穹 / DeepSeek / 百炼…）副行
- **规格 / 价格两栏**：序列长度、支持模态（文本 / 图像 / 视频 / 音频 / 向量）、最大输出长度；输入 / 输出 / 缓存命中单价（折扣时划线标原价，¥x.xx/M）、图片单价
- 折扣模型：标题行最左带**「折扣」徽章**（实底绿渐变 + 白字，行内排布、不影响卡片布局），价格栏同时划线标原价；状态胶囊只显示平台状态（在线 = 绿点 / 测试中 = 琥珀点）
- **模型清单跟随当前凭据**：密钥页选用带 API Key 的凭据后，模型列表换成该 Key 的网关清单

### 余额
- **账户余额主卡**：大字展示总余额（带千分位），右侧**限时额度** + **倒计时胶囊**（≤3 天转警示色）+ **限时占比条**（一眼看出多少是「会过期的钱」），有冻结金额时一并显示
- **当日使用**：调用次数、输入 / 输出 / 缓存 tokens、当日花费（本地 0 点起统计）
- **近 7 天花费柱状图**：悬停任一柱子浮出**当日各模型消费明细**（Top 6 + 其他）
- 每 60 秒自动刷新；临期或余额不足时顶部有预警条
- 主卡上方标注**数据归属账号**（显示平台用户名，数据按身份隔离，切换凭据或账号立即刷新）
- **侧栏条目常驻余额**：不打开面板也能在侧栏（「记忆系统 / 技能中心」下方）看到「基元费用」行的当前余额，切换凭据随之更新；**悬停该行**浮出限时余额时间线（逐笔列出每笔限时额度和「N 天后失效」，无限时额度时不显示）；设置页可把胶囊切换为**总余额 / 限时总余额**二选一

### 密钥（本机凭据池）
- **保存**：只填 API Key 和/或 Cookie 即可保存（API Key 用于拉取模型清单；Cookie —— `tr_session`，整段 Cookie 也认 —— 用于查询余额与用量）。**保存只入库，不会改变当前使用的凭据**
- **列表**：每条两行**完整展示**保存的 API Key 与 Cookie 原文，右侧「删除 / 使用」两个按钮；点「使用」后该按钮变为「当前」，身份随之切换
- **使用即生效**：模型清单换成该凭据的 API Key，余额 / 用量 / 账单换成该凭据的 Cookie；切换后旧身份的余额缓存立即失效
- **删除**：移除该条记录；若删的是当前使用项，会同时解除它在模型（API Key）与余额（Cookie）上的应用——之后余额 / 用量随即不可查（除非到设置页用账号密码登录）
- 凭据只存在本机 `~/.dsh/tokenrhythm-bill-state.json`（0600）

### ZCode（v0.5.0 新增，默认关闭）
- **总开关**：本插件面向所有用户发放，读本机 ZCode 凭证的能力**默认关闭**——设置弹窗「ZCode 集成」卡里显式「开启」后，面板标题切换器才会出现「ZCode」段，插件后台才被允许访问 `~/.zcode/v2`（host 侧路由同样有门禁，双重保险）；关闭即停读，面板恢复原样
- **用量页签**：读取本机 `~/.zcode/v2` 的 ZCode 桌面端登录凭证，直连官方接口查询当前套餐（档位 / 到期 / 剩余额度 / 已用占比）；BigModel 通道优先，自动回退 z.ai 余额接口，兼容个人订阅与活动赠送多套餐切片。每 60 秒自动刷新
- **活动页签**：列出可领取的 ZCode 活动套餐（赠送内容、周期），一键领取——领取前自动打激活埋点，通过阿里云验证码（先 8 秒无感验证、风控时转滑块）后自动提交；验证码弹窗页由插件后台伺服，若被页面 CSP 拦截会自动回退到 127.0.0.1 一次性端口完成，结果回传面板
- **入口胶囊**：切到 ZCode 时侧栏胶囊同步换成 ZCode 身份（闪电图标 + 套餐剩余百分比），无数据时自动回落基元余额
- 凭证解密、token 候选与请求头伪装逻辑移植自开源工具 [zcode-switch](https://github.com/pjpv/zcode-switch) v1.5.4（MIT），并用其跨语言测试向量对拍锁定
- **安全与风险**：ZCode 凭证只在插件后台内存与 `~/.zcode/v2` 本机文件中出现，浏览器只见掩码；相关接口为官方未公开接口、请求头伪装成桌面端，存在被平台风控的可能，请自行斟酌使用

### 设置（面板右上角 ⚙，弹窗打开）
- **账号管理**：添加 / 一键切换 / 删除**多个**基元律动账号（手机号 + 密码），密码保存在本机、随时可明文查看
- **入口胶囊余额**：侧栏入口胶囊显示「总余额」或「限时总余额」，点击即切换并记住选择
- **插件更新**：自动比对 npm 最新版本（24 小时缓存），有新版时状态转高亮并提供「复制更新命令」，只提醒不自动执行

## 安装说明

任选以下一种方式安装，**安装后需重启 DSH**，侧栏里才会出现条目。

**方式一：插件市场**（收录后可用）

在 DSH 插件市场搜索「基元律动费用中心」或 `dsh-tokenrhythm-bill`，一键安装。

**方式二：命令行 · npm 源**（推荐，秒级安装）

```sh
dsh plugin --profile web add dsh-tokenrhythm-bill
```

> 已装过旧版本？重复执行上述命令即可**更新**到最新版，然后重启 DSH。

## 首次配置

1. 点击侧栏里的「基元费用」条目 → 「密钥」页
2. 填 **API Key**（拉模型清单）和/或 **Cookie**（查余额与用量），点「保存」
3. 在下方列表里点该条的「**使用**」，再回到「余额 / 模型」页签即可使用

> **怎么拿这两样？** API Key 在 [tokenrhythm.studio](https://tokenrhythm.studio) 的账户页新建；Cookie 在浏览器登录后按 F12 → 应用 → Cookie，复制 `tr_session` 的值（整段 Cookie 粘贴也认）。两者都只保存在本机。

> **会话自动续期**：若在设置页添加了账号密码，会话过期时插件会**自动重登同一账号**并继续刚才的操作，全程无感；只配了 Cookie 的凭据过期后，重新到密钥页更新 Cookie 即可。

## 隐私说明

- 凭据（API Key、会话 Cookie、账号密码）只保存在**本机** `~/.dsh/tokenrhythm-bill-state.json`（0600），不上传任何服务器
- 密钥页按你的要求原样展示保存的 API Key 与 Cookie，供本机核对；其它页面不展示凭据

## 常见问题

- **切换凭据后图表变成 ¥0？** 余额、用量、趋势都按身份隔离——切到没数据的凭据自然为空，切回原凭据即恢复原数据。
- **余额显示「会话已过期」？** 到「密钥」页更新该凭据的 Cookie，或在设置页用账号密码重新登录。
